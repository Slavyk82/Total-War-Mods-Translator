## What's New — v2.0.7

### Mods
- Switching game from the sidebar now rescans that game's mods folder, with the same progress window as at startup, instead of quietly reusing the list from before. The startup rule applies: each game is scanned once per session, so switching back to a game you already scanned stays instant. The Refresh button on the Mods screen still forces a scan at any time.

### Backups
- The rolling automatic backup is now taken weekly instead of on every launch — opening the app several times a day no longer costs a backup each time. A fresh install still gets its first backup right away, and a backup older than a week is still replaced at startup.
